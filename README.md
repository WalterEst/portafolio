# Portafolio de Walter Vásquez Bustos

Soy desarrollador full stack y cofundador de Harpa SpA. Estos proyectos reúnen trabajo en sistemas de gestión, comercio y seguimiento institucional.

## Punto de venta de Harpa

Desarrollé la mayor parte del punto de venta sobre una base que incluía aportes de compañeros. Implementé la impresión térmica de boletas, la vista previa y las pruebas de impresión. El sistema utiliza Angular, Express, TypeScript y MySQL.

[Ver punto de venta](https://pos.avicolalasmariposas.cl/)

## ERP avícola de Harpa

Desarrollo en equipo de un ERP en producción para la operación avícola. Participé en la planificación, el modelado de datos y el desarrollo con Angular y NestJS. También gestiono el hosting y el despliegue a producción.

[Ver ERP avícola](https://avicola.harpa.cl/)

## Sitio web de Avícola Las Mariposas

Desarrollé y desplegué el sitio web y su sistema de gestión de publicaciones y catálogo de productos. El frontend está construido con Angular y el backend con NestJS.

[Ver sitio web](https://avicolalasmariposas.cl/)

## Cuadro de Mando Integral de Dirplac UNACH

Desarrollé durante mi práctica intermedia un sistema para seguir objetivos, indicadores y metas institucionales. Utilicé Angular, Express y MySQL y participé desde el levantamiento de requerimientos hasta el despliegue.

[Ver Cuadro de Mando Integral](https://cmi-dirplac.unach.cl/)

## Aprendizaje profundo aplicado a accesibilidad

En colaboración con Coanil en Chillán, desarrollamos un juego web para que niñas y niños con movilidad reducida pudieran jugar con la mirada y el parpadeo.

Integré MediaPipe Face Landmarker y una red neuronal convolucional con TensorFlow Lite para estimar la mirada. Implementé el modo móvil, que procesa la imagen de la cámara en el navegador, y ajusté la detección de parpadeos para controlar el juego.
